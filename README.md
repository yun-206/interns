# interns

동기 4명이 같이 쓰는 작은 사이트예요. **쪽지·단체방, 공지사항, 일정 공유(연차·반차·출장), 점심 뽑기**를 한곳에 모았어요.
팀 허브(teamhub_00)의 화면 틀과 코드를 가져와 기능만 바꿔 만들었어요. 빌드 없이 HTML·CSS·바닐라 JS만 써요.

## 화면
| 주소 | 내용 |
|---|---|
| `/` | 홈: 인사·요약(오늘 일정 있는 사람 / 안 읽은 쪽지 / 접속 중), 이번 주 일정, 오늘 점심, 공지, 최근 활동, 멤버 |
| `/join.html` | 입장: 비밀번호 → 이름·소속(선택). 초대 링크는 `/join.html?invite=1` |
| `/messages.html` | 쪽지: **단체방** + 멤버별 1:1. 말풍선 옆 노란 숫자 = 아직 안 읽은 사람 수. **사진·파일 첨부**(📎 버튼 / 끌어다 놓기 / Ctrl+V 붙여넣기) |
| `/schedule.html` | 일정 공유: 월간 달력. 연차·오전/오후 반차·출장·외근·교육·재택·기타 + **멤버가 직접 만든 종류**(이름·색), 여러 날 가능. 내 일정은 눌러서 **수정·삭제** |
| `/lunch.html` | 점심 뽑기: 후보 1~4개 → 돌림판 / 랜덤 뽑기. 결과는 다른 멤버 화면에서도 같은 애니메이션으로 재생 |
| `/notices.html` | 공지사항: 공지·약속·정보 |
| `/omok.html` | 미니게임 오목: **컴퓨터와**(흑/백 고르기, 쉬움·보통, 무르기) / **동기와**(대국 신청 → 수락 → 각자 화면에서 실시간으로 번갈아 두기, 관전 가능) |
| `/baseball.html` | 미니게임 숫자야구: **혼자**(컴퓨터가 숨긴 3자리 10번·4자리 12번 안에) / **동기와**(서로 숫자 숨기고 번갈아 맞히기, 판정은 서버) |

- 상단: 단체방 바로가기(안 읽은 수), 알림 종(공지·쪽지·일정·점심 소식, 실시간 토스트), 프로필(상태: 온라인·바쁨·자리 비움 / 초대 / 테마 / 이 기기에서 나가기 / 전체 초기화)
- 멤버 목록에 접속 상태와 **오늘 연차·출장** 같은 표시가 같이 떠요
- 한 번 들어온 기기는 다음부터 바로 열려요. 다른 기기에선 같은 이름으로 들어오면 기존 멤버로 이어져요

## 오목
- 15×15, **흑이 먼저**. 다섯 개 이상 이으면 승. **흑만 33 금지**(열린 3 두 개를 한 번에 만드는 수) — 금지 자리는 판에 ×로 보이고 둘 수 없어요. 4·3, 44, 장목은 허용
- 컴퓨터와: 내 돌(흑·먼저 / 백·나중)과 난이도(쉬움·보통)를 골라 시작. 무르기·새 판. 두던 판과 전적은 이 기기에 저장
- 동기와: 상대·내 돌(흑/백/랜덤) 골라 **대국 신청** → 상대에게 알림 → 수락하면 시작. 상대가 두면 바로 내 화면에 뜨고, 다른 페이지에 있어도 '내 차례' 알림. 기권(두 번 눌러 확인), 끝나면 '한 판 더(돌 바꿔서)'
- 다른 멤버 대국은 관전만 가능. 차례·빈칸·5목 판정은 서버 함수(`omok_move`)가 확인해요(33 금지는 화면에서 막음)
- 이기면 최근 활동에 '오목에서 이겼어요'

## 숫자야구
- 서로 다른 숫자 3·4자리. 숫자·자리 맞으면 S, 숫자만 맞으면 B, 하나도 없으면 OUT. 0도 쓸 수 있어요
- 입력: 숫자판 또는 키보드(숫자·Backspace·Enter·Esc). 같은 숫자는 막혀요. 메모판(숫자마다 없음/있음/모름)
- 혼자: 3자리 10번 / 4자리 12번 안에. '남은 후보 수' 힌트(선택), 포기하면 정답 공개, 자릿수별 전적·최고 기록(이 기기)
- 동기와: 상대·자릿수 골라 신청 → 수락 → 각자 숫자 숨기기(🎲 랜덤 가능) → 신청자부터 번갈아 부르기. 먼저 맞히면 승, 단 신청자가 맞히면 상대에게 같은 횟수 기회를 한 번 더 → 둘 다 맞히면 무승부. 30번씩 해도 못 맞히면 무승부
- 숨긴 숫자는 `bb_secrets` 표에 있고 **본인만** 읽을 수 있어요(끝난 뒤에만 상대에게 공개). S·B 판정은 서버 함수 `bb_guess`가 해요
- 이기면 최근 활동에 '숫자야구에서 이겼어요'

## 일정 종류 직접 만들기
- 일정 올리기 창의 종류 칩 끝 **＋ 직접 만들기** → 이름(10자까지)·색 8개 중 하나 → 추가하면 바로 골라져요
- 만든 종류는 **모든 멤버가 같이** 써요(달력 범례에도 떠요). 이미 있는 이름을 적으면 새로 만들지 않고 그걸 골라요
- 지우기(×)는 **만든 사람만**. 지워도 이미 올린 일정의 글자는 그대로 남고 회색으로 보여요
- 30개까지
- 이름에 '반차'가 들어가면 기본 반차처럼 하루만 고를 수 있어요

## 첨부 (사진·파일)
- 1:1·단체방 모두 가능. 📎 버튼으로 고르거나, 탐색기에서 대화창으로 **끌어다 놓거나**, 캡처한 사진을 **Ctrl+V**로 붙여넣기
- 한 번에 10개, 파일당 10MB까지. 큰 사진은 보내기 전에 긴 변 1920px JPEG로 줄여요(GIF는 그대로)
- html·js·exe 같은 실행 파일은 막아요
- 사진은 말풍선에 바로 보이고, 누르면 크게 보기(← → 로 넘기기, 저장). 그 밖의 파일은 눌러서 받기
- 파일은 Supabase Storage의 **비공개** 버킷 `chat-files`에 저장. 링크는 1시간짜리 서명 URL이라 밖으로 새도 곧 만료돼요
- 폴더 규칙: 단체방 `group/…`, 1:1 `두 사람 id 정렬_…/` → **1:1 파일은 두 사람만** 받을 수 있어요(Storage RLS)
- 전체 초기화하면 첨부 파일도 같이 지워져요
- 무료 플랜 Storage 1GB면 이 정도 용도엔 충분해요

## 처음 설정 (Supabase)
1. supabase.com에서 프로젝트 만들기 (Region: Northeast Asia (Seoul))
2. **Authentication → Sign In / Providers → Allow anonymous sign-ins 켜기** (기기 인증에 써요)
3. **SQL Editor**에 `supabase/setup.sql` 통째로 붙여넣고 Run (여러 번 실행해도 안전 · 첨부용 Storage 버킷과 규칙도 여기서 같이 만들어져요)
4. **비밀번호 정하기** — SQL Editor에서 아래 한 줄을 따로 Run (이 줄은 저장소에 올리지 않아요)
   ```sql
   insert into public.app_settings (key, value) values ('password', '여기에_비밀번호') on conflict (key) do update set value = excluded.value;
   ```
5. Project Settings → API Keys의 **Project URL**과 **Publishable key**를 `data/team.js`의 `supabase`에 넣기
   (Publishable 키는 공개용이라 저장소에 올라가도 괜찮아요. **secret·service_role 키는 절대 넣지 말 것**)
6. 이 저장소를 Vercel에 연결 (빌드 설정 없음)

무료 프로젝트는 일주일쯤 안 쓰면 일시정지돼요 → 대시보드에서 Restore.

## 보안 구조
- 브라우저는 기기마다 **익명 로그인** 사용자를 하나 받아요. 비밀번호를 맞혀 입장하면 그 기기가 멤버와 연결돼요(`member_devices`).
- 모든 표는 **입장한 기기만** 읽을 수 있어요(RLS). 비밀번호 없이 익명 로그인만 해서는 아무것도 못 읽어요.
- **1:1 쪽지는 보낸 사람·받은 사람만** 읽을 수 있어요. 단체방은 멤버 모두.
- 글·일정·점심 기록은 **자기 이름으로만** 쓸 수 있고, 공지·일정은 자기 것만 지울 수 있어요. 일정 수정도 자기 것만, 종류·날짜·메모 칸만 바꿀 수 있어요. 쪽지는 읽음 표시(`read_at`)만 바꿀 수 있어요.
- 비밀번호는 DB(`app_settings`)에만 있고 브라우저에서 읽을 수 없어요. 함수 안에서만 비교해요.
- 한계: 비밀번호를 아는 사람은 아무 이름으로나 들어올 수 있어요(같은 이름이면 그 멤버로 이어짐). 4명끼리 쓰는 용도라 이 정도로 정했어요.

## 미리보기 모드
`data/team.js`의 `supabase` 값을 비우고 `password`를 넣으면 이 브라우저 안에서만 돌아가는 미리보기 모드가 돼요(같은 브라우저 탭끼리만 공유). 미리보기 모드의 첨부는 브라우저 저장 공간이 작아서 1MB까지만 돼요.
